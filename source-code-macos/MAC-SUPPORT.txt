GeoCheats v1 - Native Mac support status

The Mac application builds and supports game linking and file inspection.
The seven bundled recipes were derived from a Windows executable and are not
used against a native Mac game. The Mac controller now tries a local, exact-symbol
discovery route for experimental Intel invincibility, without requiring a game
upload. It looks for PlayLayer::destroyPlayer(PlayerObject*, GameObject*) in the
thin Intel Mach-O symbol table, checks its executable section and frame prologue,
and creates an exact SHA-256 recipe with live guards. Missing/ambiguous symbols,
different prologues and unsupported binaries produce a useful error, not a guess.

Use Dash's Advanced controls to inspect and export the experimental recipe.

This has synthetic-file tests, not a real Mac gameplay test. Native ARM64 game
instruction-cache synchronization and universal game slice support remain blocked.
An Apple Silicon GeoCheats app can attempt a thin Intel game's recipe; this does
not make ARM64 game code compatible. Native high jump, speed, no jump, flight and
completion still require independently verified Mac profiles.

Windows uses PE images and Windows process APIs; macOS uses Mach-O/dyld images
and Mach task APIs. Memory layouts and instruction sets differ. No kernel driver
or protocol conversion makes Windows RVAs valid on macOS. Apple's task_for_pid
policy can deny access even when a recipe is correct. This app does not bypass
SIP or modify game entitlements/signatures. See:
https://developer.apple.com/documentation/bundleresources/entitlements/com.apple.security.cs.debugger
https://github.com/geode-sdk/bindings

Switches are remembered until disabled, with automatic reconnection and a
removable user LaunchAgent login item. Move GeoCheats.app into its final location
before enabling mods. Quit restores runtime patches and retains preferences;
closing the native window hides it and leaves the controller running. A stopped controller cannot
keep per-frame effects running. Deleting app settings removes saved switches.

For future analysis of unsupported native modes, the useful game file is:
1. On your Mac, open Steam > Library > Geometry Dash.
2. Use Manage > Browse local files.
3. Right-click Geometry Dash.app and choose Show Package Contents.
4. Open Contents > MacOS.
5. Upload the Geometry Dash executable from that folder to this conversation.
   If the upload rejects a file without an extension, compress that file into
   a ZIP and upload the ZIP. Do not modify the original installed game.

This enables analysis of the native Mach-O functions and signatures. Actual
Mac testing is still necessary, and macOS may restrict task-memory access.
Native ARM64 code patching additionally needs instruction-cache support.
No real Mac gameplay compatibility is claimed based on compilation or synthetic tests.

Native desktop update 1.3.1:
The file chooser accepts the actual .app bundle and resolves CFBundleExecutable.
Steam manifests, extra libraries and both common bundle spellings are searched.
The ZIP has only GeoCheats.app and Dash.app. Guides, notices, signing status and
Dash resources are inside the apps. Native GUI launch tests do not change the game
compatibility limitations described above.
