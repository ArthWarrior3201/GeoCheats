2 / Build a .dash recipe
Use addresses and expected bytes you have independently verified. Dash checks the complete file fingerprint and byte signatures. A successful build does not prove gameplay behavior.

The command-line Dash tool is retained for scripts. Read mod_building_guide.txt for the full schema, compatibility limits, signature discovery and testing requirements. Native ARM64 and universal game code patches remain unsupported.
